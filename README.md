# 🌎 SIATMA — Sistema Integral de Alerta Temprana Multi-Amenaza

**SIATMA** es una plataforma predictiva basada en Inteligencia Artificial que anticipa deslizamientos, inundaciones y sequías con hasta 96 horas de anticipación. Combina modelos de machine learning, datos satelitales, meteorológicos y comunitarios para generar alertas tempranas, visualizaciones interactivas y estrategias de mitigación.
